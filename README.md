## 📌 Project Overview
**BridalGlow** is a modern, fully responsive frontend web platform built as part of the Web Development Internship Task (**Task Code: WD-MAT-003**). ## 🛠️ Tech Stack & Architecture
* **Markup & Structure:** HTML5 (Semantic elements, modals, responsive containers)
* **Styling & Design:** CSS3 (Custom CSS variables, Flexbox, CSS Grid, media queries, Dark Mode)
* **Application Logic:** JavaScript (ES6+, DOM manipulation, event handling, local data persistence)
* **Data Storage:** Browser `LocalStorage` (Client-side simulation of database for users, bookings, and wishlists)
* **Hosting & Version Control:** Vercel & GitHub

---

## ✨ Key Features
1. **User Authentication & Profile Management:** Secure client-side registration and login modals with password visibility toggles. Persistent session handling via `bg_currentUser`, with options to update details, securely change passwords, or delete accounts.
2. **Advanced Artist Directory & Filtering:** Real-time multi-parameter sorting and filtering by category (Makeup, Mehndi, Photography, Decor), location, minimum rating, and budget.
3. **Interactive Booking & Wishlist System:** Instant service reservation with customizable package options, date/time pickers, and confirmed appointment tracking on the user dashboard.
4. **Theme Customization:** Integrated Light/Dark mode toggle for enhanced user experience across all viewports.
5. **Responsive Design:** Optimized layout ensuring smooth usability across desktop, tablet, and mobile devices.

## 🚀 Setup & Local Installation Instructions
To run this project locally on your machine, follow these simple steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/NiteenKumarPrasad/bridalglow-services.git
   ```
2. **Navigate to Project Directory:**
   ```bash
   cd bridalglow-services
   ```
3. **Open the Project:**
   * Open the folder in **Visual Studio Code**.
   * Run the project using the **Live Server** extension (right-click `index.html` -> *Open with Live Server*).
